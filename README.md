The plain link opens in Parchment. To change that, set `mode:` in the details block (see below).

## What guests see
One swipe, mouse-wheel scroll or arrow key moves one page, and that page then plays its animation by itself:
1. **Bismillah:** sepia sprigs draw themselves into the corners.
2. **The bride's family** (D/O Mr. Abbas T M & Mrs. Jaleela Abbas), then "Together with our families, we request the honour of your presence at the wedding of".
3. **The names:** Asna Abbas & Shinas Ismail are written letter by letter between two leafy garlands, with the groom's family below.
4. **Wedding on:** the date with the Hijri date, the venue, and a clock whose hands turn to 11:30. On computers, a QR code opens the venue in Google Maps.
5. **A live countdown.**
6. **The details**, with Open in Maps, Add to Calendar and Google Calendar buttons.
7. **Sharing happiness from Badusha Abbas.**

**Kept off this public page on purpose:** the families' house addresses and the phone number. If you want them shown, fill in `brideHome`, `groomHome`, `phone` and `whatsapp` in the details block. Filling in `whatsapp` adds a Confirm on WhatsApp button. Anyone who opens the page will then see them.

## Change the details (works from a phone too)
1. Open **index.html** in this repo and tap the **pencil (Edit)** button.
2. Search for **EDIT THE DETAILS HERE**. Everything on the page reads from that block: names, families, date, time, Hijri date, venue, maps link, host and the starting look.
3. Change only what is between the quote marks and keep the commas.
4. Tap **Commit changes**. The live page updates in about a minute; refresh it.

**Note:** the QR code is drawn for the current Maps link. If you change `maps:`, the Open in Maps button follows straight away, but ask for the QR code to be redrawn.
